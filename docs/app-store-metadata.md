## Name Options (Pick One)

Marco hasn't picked a name yet. Five options:

1. **Nibble** — friendly, short, memorable. Risk: sounds niche/snacking-focused.
2. **Calcount** — descriptive, no confusion about what it does. Risk: boring.
3. **Portio** — suggests portions, elegant. Risk: non-obvious at a glance.
4. **Macrosnap** — highlights the photo feature. Risk: sounds like a filter app.
5. **Kcal** — direct, technical, no pretense. Risk: appeals to gym crowd specifically.

**Recommendation:** Nibble or Kcal. Nibble is friendlier for casual users. Kcal signals exactly what it is to the target user and has zero ambiguity.

Check App Store availability before committing.
